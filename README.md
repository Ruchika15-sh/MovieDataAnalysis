# MovieDataAnalysis
This project was made 6 months before just to get me started on the data science basics. 
This project explores a movie dataset using Python to uncover key trends in audience ratings, genres, and box office performance. By leveraging libraries like Pandas, Matplotlib, and Seaborn, the analysis cleans raw movie data and visualizes crucial insights, such as the relationship between production budgets and revenue. It serves as a practical showcase of foundational exploratory data analysis (EDA) and data storytelling techniques.
